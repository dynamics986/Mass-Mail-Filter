# CUHK MailRoute — CUHK Mass Mail筛选器

[English](./README.md) | [中文](./README_zh.md)

CUHK MailRoute 将香港中文大学 Undergraduate Digest 整理为清晰的机会推荐，帮助学生比较机会、判断资格、跟踪日期，并返回权威的 CUHK 原始网页核对信息。在线版本：

> [https://dynamics986.github.io/Mass-Mail-Filter/](https://dynamics986.github.io/Mass-Mail-Filter/)

网站支持渐进式 Web 应用。在兼容浏览器中可以安装到设备；网络不可用时，浏览器可能继续使用已缓存的公开数据。

## 主要功能

- 按`契合、紧急、价值、意义和综合得分`排列机会。
- 筛选有薪工作、研究、活动课程、有报酬和即将截止的机会。
- 收藏、隐藏、选择和检索机会。
- 通过“减少此类 / 更多此类”调整推荐偏好。
- 在时间线和月历中查看截止日期及活动日期。
- 通过唯一且经过校验的“查看原文”入口打开 CUHK 原网页。
- 导入 Markdown 邮件，并合并到本机推荐流与时间线。
- 使用自己的 AI API Key 润色短标题和结构化摘要。
- 通过页眉右上角按钮统一切换整个网站的中英文界面。


## 开始使用

### 1. 完成个人设置

第一次打开网站时，请完成简短的资料引导。CUHK MailRoute 会根据学院、专业、学习阶段、目标类型和语言偏好计算推荐分数。之后可以在“个人设置”中修改这些信息。

### 2. 浏览推荐

打开“为你推荐”查看排序后的机会卡片。卡片上方的工具可以用来：

- 切换推荐模式和本周行动；
- 搜索标题或摘要；
- 按机会类型筛选；
- 按综合、紧急、价值或契合排序；
- 显示与当前偏好明显不符合的项目；
- 设置各评分维度的最低门槛。

每张卡片会显示简短标题与摘要、实用标签、评分维度、已知报酬、截止信息，以及查看详情、收藏和隐藏操作。

### 3. 查看详情和原始网页

点击“查看详情”可以查看匹配概览、规范化资格要求和关键信息。

如需核对内容，请使用唯一的“查看原文”链接打开权威 CUHK 页面。

### 4. 调整推荐

在机会详情页中：

- “减少此类”会降低相似类目的推荐权重。
- “更多此类”会提高相似类目的推荐权重。
- 再次点击当前已选选项即可取消。
- “标记抽取有误”用于记录解析问题，也可以再次点击取消。

这些单项反馈不会删除在“个人设置”中主动选择的目标或排除项。

### 5. 使用日程

打开“日程一览”查看截止日期和活动日期。可以选择“仅截止”精简内容，也可以通过“显示全部（含已隐藏）”检查被过滤的项目。

### 6. 检索归档和每周公告

- “归档检索”可以搜索当前、已收藏、已隐藏和本机归档的项目。
- “每周公告”最多显示最近四期已收录的 Undergraduate Digest，并链接到每一期 CUHK 官方公告列表。

## 导入 Markdown 邮件

“导入邮件”页面支持本机 Markdown 导入：

1. 下载或打开 Markdown 模板。
2. 让 OpenClaw 按模板结构导出邮箱消息。
3. 上传 `.md` 文件或粘贴内容。
4. 检查解析预览。
5. 将需要的项目合并到推荐流和时间线。

解析过程在浏览器中完成，导入内容保存在当前浏览器的本地存储中。请勿把私人邮箱文件提交到代码仓库、Issue 或发送给项目维护者。

## AI 服务（Pro）

AI 功能为可选功能。目前支持以下 OpenAI-compatible 服务商：

- 硅基流动
- DeepSeek
- Kimi
- 阿里云百炼（DashScope）
- 百度智能云千帆
- 豆包（火山方舟）
- 智谱 AI
- 魔搭 ModelScope
- MiniMax
- 腾讯混元
- OpenAI
- OpenRouter

### 配置 AI

1. 打开“个人设置”。
2. 启用“AI 增强摘要 / 翻译”。
3. 选择服务商。
4. 输入该服务商的 API Key 或 Access Token。
5. 确认或修改模型 / 接入点 ID。
6. 一般无需填写 Base URL；只有服务商提供其他兼容地址、代理地址或区域端点时才需要修改。
7. 点击“测试连接”。成功后会显示服务商、模型和模型的简短回复。
8. 保存设置。

API Key 输入提示会根据服务商变化。并非所有凭据都以 `sk-` 开头：例如 ModelScope 使用 Access Token，智谱 Key 可能采用 `ID.secret` 格式。

### 一键润色

在推荐页点击“一键润色本页”。CUHK MailRoute 会：

- 跳过仍然有效的本机缓存；
- 只向当前服务商发送经过压缩且与事实相关的邮件片段；
- 顺序处理请求，降低触发限流的可能；
- 遇到认证、权限、额度、模型、网络或响应格式等服务商级错误时停止；
- 显示明确原因和未处理数量。

更换服务商、模型或修改原始邮件后，对应缓存会失效。AI 结果不会覆盖原始导入数据。

### AI 隐私与费用

服务商凭据和 AI 缓存保存在当前浏览器中，不会包含在个人设置导出文件内。使用润色或 AI 翻译时，相关邮件文本会由浏览器直接发送给所选服务商，并可能产生服务商费用。

浏览器本地存储并不是加密的密码保险库。建议使用受限且设置消费额度的 API Key，不要在共用或不可信设备上配置凭据。

## 本机数据与隐私

CUHK MailRoute 是纯前端浏览器应用，以下内容会保存在当前浏览器：

- 个人设置和推荐偏好；
- 已收藏、已隐藏和导入的机会；
- 单项反馈和抽取错误标记；
- AI 服务商配置与凭据；
- AI 润色缓存；
- CUHK 公开数据缓存。

可以在“个人设置”中使用“导出”备份可导出的偏好状态，API 凭据会被排除。“清除本地数据”会重置当前浏览器保存的个人信息、偏好、收藏和导入项目。

## 本地运行

环境要求：

- Node.js 22 或更高版本
- npm

```bash
npm install && npm run dev
```

打开 Vite 输出的本地地址，通常是 [http://localhost:5173/](http://localhost:5173/)。

提交修改前运行：

```bash
npm test
npm run build
```

本地预览生产构建：

```bash
npm run preview
```

## 更新公开 Digest 数据

Python 数据流水线会抓取 CUHK 公开 Undergraduate Digest 页面，校验并增强记录，清除示例数据，并保留最近四期 Digest 和仍然有效的机会。

环境要求：

- Python 3.12
- `requirements.txt` 中的依赖

```bash
python -m pip install -r requirements.txt
python -m pytest -q tests
python -m pipeline.main --lookback-days 28
```

抓取指定日期（格式为 `YYYYMMDD`）：

```bash
python -m pipeline.main --date 20260717
```

GitHub Actions 中的 **Update CUHK digest data** 工作流会定时运行，也支持手动触发。它会先测试数据流水线，再检查最近 28 天，并且只在 `public/data` 发生变化时提交更新。
