# 网站修改记录

## 排版与视觉

- 统一页眉与页面主体的最大宽度和响应式水平留白，使左右边缘保持对齐。
- 统一首页与次级页面的标题位置、响应式字号、行高和垂直节奏。
- 删除重复的眉题、宣传说明和过长的页眉格言，避免标题冗余及导航换行。
- 将非标题文字和操作控件统一到现代无衬线字体栈，并统一按钮字号、字重和行高。
- 统一胶囊按钮、设置表单、下拉框和主要操作按钮的高度、内边距、边框与状态样式。
- 为路由切换预留稳定的滚动条空间，避免页面横向跳动。
- 为条件出现的“重置拉杆”预留固定空间，避免分数门槛面板移动或改变大小。
- 修复长链接、长标题、长标签和无断点文字在推荐卡片、日程卡片、归档及详情页中的溢出。
- 补充标准 `line-clamp` 属性，同时保留浏览器前缀以提高兼容性。
- 将普通标签和资格标签放入同一个可换行容器，空间足够时显示在同一行。
- 将 PWA 与站点图标改为透明背景，使浏览器标签页、主屏幕和安装界面显示更自然。
- 保留页面底部的流式版权信息，避免覆盖正文或移动端导航。

## 导航与响应式

- 将六个中文主导航名称统一为四个字符：为你推荐、日程一览、导入邮件、归档检索、每周公告、个人设置。
- 保持桌面端菜单右对齐，并为中等宽度浏览器压缩间距和字号。
- 在窄屏继续使用移动端导航，并让多列页面逐步折叠为两列和单列。
- 防止复选框、按钮和文字标签在窄列中被拉伸或变成竖排文字。
- 将首页 Hero 标题设为“为你推荐 / For you”，将结果区标题设为“机会精选 / Curated opportunities”。

## 推荐页与卡片

- 将推荐控制区整理为模式、搜索、筛选、排序和分数门槛等清晰分组。
- 将控制区第一行设为模式、搜索、筛选，第二行设为排序及横跨两列的分数门槛，并加入响应式折叠。
- 将“包含资格不符项目”从工具栏移到“一键润色本页”旁边，并使用可区分的按钮样式。
- 移除“一键润色本页”旁边重复的项目总数，只在按钮内显示仍待润色的数量。
- 当 AI 配置缺失时，再次点击“一键润色本页”可以收起提示。
- 移除推荐卡片和详情页的单项润色按钮，保留页面级批量润色。
- 改进卡片选择控件、选中状态、资格状态位置及批量操作栏的一致性。
- 保持“查看详情”为卡片主操作，将收藏和隐藏作为次级操作。
- 清理标题和梗概中的装饰性表情符号，并改进标题与梗概重复内容的识别。
- 删除原始评分轨迹、技术标签和资格要求下方无关的抽取证据。

## 详情页

- 删除标题上方重复的资格状态、类目和发布日期，让标题成为详情内容的起点。
- 将纯文字返回链接升级为浅紫描边胶囊按钮。
- 从站内页面进入详情时返回上一页，直接打开详情链接时返回首页。
- 缩小并约束详情标题宽度，使长中英文标题自然换行。
- 删除完整邮件正文和重复的申请链接列表。
- 将唯一的“查看原文 / View source”移到标题梗概下方，并保留安全的新标签页打开方式。
- 没有有效来源链接时显示低强调度说明，不显示空按钮。
- 将“查看原文”改为清晰但克制的浅绿色主按钮。
- 将“减少此类”“更多此类”“标记抽取有误”移到“查看原文”旁边，并统一按钮尺寸。
- 从右侧信息卡移除重复的原文链接，只保留类目、报酬、截止、对象、主办方、联系方式和时间节点。
- 明确控制“匹配概览”标题与契合、紧急、价值、意义、重要评分条之间的间距。
- 保留反馈的互斥、持久和再次点击取消行为，且不影响个人设置中的目标或排除项。

## 日程、归档与每周摘要

- 将“仅截止”和“显示全部（含已隐藏）”移动到月份标题旁边，并统一为紧凑胶囊按钮。
- 让月份标题和日程筛选整体换行，保持移动端可读性。
- 删除日程页标题下方重复的说明文字，依靠筛选控件和图例解释页面。
- 拉长归档检索的搜索框，使其优先使用可用横向空间并保持响应式。
- 将每周公告限制为最新四期摘要卡片，按新到旧显示日期、索引数量和官方公告链接。
- 不在每周公告重复列出单封邮件，单项来源统一从机会详情进入。

## 导入与本地数据

- 将导入流程整理为“获取模板、Agent 导出、解析并合并”三个对齐的步骤卡片。
- 将下载和打开模板操作放入“获取模板”卡片。
- 在“Agent 导出”卡片加入可直接使用的导出说明。
- 将上传 Markdown 和清除已导入操作放入“解析并合并”卡片。
- 保留粘贴、预览和合并功能，并增加隐私提示与文本编辑区之间的间距。
- 明确说明解析和保存均在当前浏览器完成，私人邮件导出文件不应提交到仓库或公开分享。
- 更新 OpenClaw 模板、字段说明、时间节点映射、解析行为和隐私指引。

## 资格、评分与个性化

- 保留契合、紧急、价值、意义和重要五个评分维度及可调权重。
- 将“有薪工作”目标作为唯一的有薪偏好来源，同时影响契合和价值评分。
- 自动迁移旧的有薪偏好设置，并从新保存和导出的状态中移除废弃字段。
- 将“减少此类”和“更多此类”整理为同类机会的可逆偏好叠加，并保持两者互斥。
- 默认隐藏与个人资料存在高置信冲突的项目，同时允许用户主动包含这些项目。
- 修复费用和价格被误判为参与者报酬的问题，并纠正特定邮件的有效报酬抽取。
- 收紧机会类型的词边界匹配，避免 `internal` 因包含 `intern` 而被误分类。

## AI 服务

- 将单一服务商配置扩展为共享的 OpenAI 兼容客户端和多服务商注册表。
- 为每个服务商分别保存 API Key、模型 ID 和可选 Base URL，切换服务商不会清除其他配置。
- 自动迁移旧版 SiliconFlow 凭据，并继续排除个人设置导出中的 API 凭据。
- 对齐服务商、API Key、模型、Base URL 和连接测试控件的宽度与位置。
- 连接测试使用表单中尚未保存的当前值，并可在全局 AI 开关关闭时独立运行。
- 加入测试中状态、超时、分类错误提示，以及包含服务商、模型和短回复的成功结果。
- 统一润色、批量润色和翻译的服务商配置与缓存标识。
- 批量润色复用有效缓存，并在鉴权、权限、模型、额度、网络或响应等全局错误后停止重复请求。
- 将润色输入改为最多 900 字符的事实优先摘录，优先保留报酬、截止、对象、语言和资格信息。
- 精简提示词和结构化字段，将输出上限从 400 降至 220 tokens，同时继续用完整清理后原文校验缓存。
- 扩展服务商列表，并为不同服务商提供更准确的凭据占位提示。

## 中英文与内容规范

- 让语言选择覆盖导航、页面标题、控件、筛选、状态、标签、错误、提示和无障碍文本。
- 以页眉语言按钮作为唯一界面语言入口，并将选择保存在本地。
- 为分类、领域、角色、语言、年级和学生阶段等内部值加入对应的中英文显示名称。
- 保留原始邮件、机构名称、服务商名称、API／模型标识和无既定译名的专有名词。
- 更新 AI、导入、日程、摘要、反馈和空状态的中英文文案。

## 数据更新与可靠性

- 将公开数据抓取窗口和定时工作流统一为最近 28 天。
- 公共数据完整保留最新四期摘要，并继续保留仍有有效截止日期的更早项目，避免无期限累积全部历史邮件。
- 修复中文句界清理导致梗概被误判为标题重复、进而使流水线测试失败的问题，并加入回归测试。
- 在发布流程加入近期摘要验证；公开数据缺少最新可用期次时停止发布并报告缺失日期。
- 移除已废弃的 `cu-link` 分支触发配置，保留主分支与数据更新后的 Pages 部署流程。
- 明确 Vite 的 `index-<hash>.css` 属于内容哈希产物，部署时由 HTML 与资源文件成套更新，不手工固定或重命名。
- 增加报酬语境、来源链接、表情清理、梗概去重、本地化、反馈、存储迁移、评分和 AI 请求大小等测试覆盖。

## PWA、搜索与站点元数据

- 保留 Web App Manifest、Service Worker、应用外壳和公开数据运行时缓存，使网站可以安装并在断网时回退到最近缓存。
- 使用“离线模式”和“数据可能已过期”提示区分网络失败与缓存新鲜度风险。
- 增加更准确的站点描述、canonical、Open Graph、Twitter Card 和应用名称元数据。
- 新增 `sitemap.xml` 和 `robots.txt`，允许普通搜索索引并声明拒绝常见 AI 训练爬虫。
- 明确 `robots.txt` 只是自愿遵守的抓取规则，不能代替隐私和访问控制。

## 文档与工程维护

- 建立完整的英文和中文 README，并提供互相切换的链接。
- 将产品与界面长期原则集中到 `docs/design.md`，不再使用按日期排列的设计决策日志。
- 将网站运行机制精简为英中双语的 `docs/principle.md`。
- 将历次完成的修改统一集中到本文件，取代分散的日期更新记录。
- 要求用户可见行为变化同步更新设计原则、使用说明和相关验证。
